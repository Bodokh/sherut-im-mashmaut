# Public typography

Heebo is the public reading, navigation and display face. Spacious display sizing and lighter weights distinguish the titles from body copy. The font supports Hebrew and Latin and is served locally with `next/font/local`, with no visitor requests to a font CDN.

- Heebo source: existing `app/(staff)/fonts/Heebo-variable.ttf`; its SIL Open Font License is included in `Heebo-OFL.txt`.

The WOFF2 file retains basic Latin, Hebrew (including vowel marks), general punctuation and the shekel sign. It retains the original variable weight range. Generated with FontTools subset and Brotli; the original and license remain intact.
