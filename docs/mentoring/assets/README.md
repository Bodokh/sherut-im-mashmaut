# Preview font asset

Heebo Variable is bundled locally for the Hebrew-first mentoring design preview.

- File: [Heebo-variable.ttf](Heebo-variable.ttf), 122,012 bytes.
- Upstream: [Google Fonts Heebo source](https://github.com/google/fonts/tree/main/ofl/heebo).
- Downloaded on 26 October 2026 from the official `google/fonts` repository.
- Copyright: The Heebo Project Authors.
- License: [SIL Open Font License 1.1](Heebo-OFL.txt), retained alongside the font.

The font is used as a local design asset. No Google Fonts/CDN request is needed when viewing the preview. The TTF is the original downloaded variable-font file; no conversion or subsetting was performed.
