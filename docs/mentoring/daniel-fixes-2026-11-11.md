## Confirmed weekly reminder behavior

First overdue is seven Jerusalem calendar days after the latest valid completed phone/in-person contact, using the assignment follow-up anchor when there is no such contact. Repeats resolve each calendar week from that original anchor, preserving the local clock across daylight-saving changes. A nonexistent local time shifts that occurrence forward; an ambiguous time uses the earlier instant under the existing domain rule. Later weeks return to the original wall time.

The planner selects only the latest due week, so missed scheduler runs do not send a burst of historical reminders. A stable same-week delivery identity prevents duplicate accepted sends. A no-answer attempt does not reset the cycle; a new qualifying completed report supersedes pending reminders from the old cycle and starts the next seven-day cycle.
